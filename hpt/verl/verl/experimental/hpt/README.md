
# 判题规则说明（a8d25c3）

## 概述
判题分四步：
1. 检查回复格式：有 `</think>`，并且之后有完整的 `\boxed{}`。
2. 取 `</think>` 之后最后一个 `\boxed{}` 里的内容作为模型答案。
3. 根据标准答案的形式，把题目分成选择题、多空题、单空题三类。
4. 数学上是否相等，交给 legacy 判题器判断。

---

## 一、判题流程

```
收到一条模型回复
│
├─ 第 1 步：格式检查（任一项不通过，判 0 分）
│    ├─ 回复里没有 </think>
│    └─ </think> 之后没有完整的 \boxed{}
│
├─ 第 2 步：取答案
│    取 </think> 之后最后一个 \boxed{} 里的内容
│    （模型先写错、后改对时，以最后一个为准）
│
├─ 第 3 步：整理标准答案
│    数字转成文本，去掉 \boxed 外壳；
│    标准答案有多个时，对上其中任意一个就算对
│
└─ 第 4 步：按标准答案的形式分类
     ├─ 按字母顺序排列的大写字母，如 "A"、"A,C"  → 选择题
     ├─ 含有半角逗号（括号里的逗号不算）         → 多空题
     └─ 其他                                    → 单空题
```

### 选择题
1. 先交给 legacy 判题器判，判对就给 1 分。
2. 判错的话，再从模型答案里解析选项字母：
   - 全角和半角都认，`ＡＣ` 等同于 `AC`；
   - 字母之间可以不分隔，也可以用 `,`、`、`、`;`、空格或括号分隔；
   - 不看顺序，`CA` 等同于 `A,C`；
   - 出现字母以外的内容就判错，比如 `A或C`、`选A`；
   - 字母重复就判错，比如 `II`、`AAC`。

### 多空题
1. 标准答案按半角逗号拆成若干个空，顺序固定。
2. 模型答案按 `,` `，` `;` `；` 拆分，空的数量必须一样。
3. 按顺序逐个空比较，全部对上才给分，所以 `3,2` 对 `2,3` 判错。
4. 每个空的比较方法和单空题相同。

### 单空题
1. 检查标签：两边都写了 `x=…` 这类标签时，标签必须一致。比较标签时忽略空格和花括号，所以 `x_{1}` 和 `x_1` 算同一个标签。
2. 两边都去掉末尾的单位。
3. 交给 legacy 判题器判断数学上是否相等。

## 二、规则清单

### A. 格式与答案提取
| 编号 | 规则 | 例子 |
|---|---|---|
| A1 | 没有 `</think>`，判 0 分 | 只在思考过程里写了 `\boxed{3}` |
| A2 | 只看 `</think>` 之后的最后一个 box | `\boxed{5} 改正：\boxed{3}`，取 3 |
| A3 | 标准答案统一整理成文本 | `3`、`"\boxed{3}"`、`["5","3"]` 都能处理 |
| A4 | 取不到 `\boxed {3}`（中间有空格）和 `\fbox{3}` 里的答案，判 0 分 | — |

### B. 单位
| 编号 | 规则 | 例子 |
|---|---|---|
| B1 | 去掉百分号和度数符号 | `25%` = `25`，`30°` = `30`，`30^\circ` = `30` |
| B2 | 去掉 LaTeX 包起来的单位 | `5\text{ cm}` = `5`，`5\mathrm{~m}` = `5` |
| B3 | 去掉常见的多字母公制单位 | `5cm` = `5`，`3 km` = `3` |
| B4 | 不做单位换算 | `50cm` ≠ `0.5` |
| B5 | 百分数和小数不互换 | `25%` ≠ `0.25` |
| B6 | 中文单位和裸写的单字母单位不去掉，交给 legacy 判；legacy 会判 `5厘米` = `5`、`30度` = `30`、`2m` = `2` | — |

### C. 多空题
| 编号 | 规则 | 例子 |
|---|---|---|
| C1 | 标准答案里括号外的半角逗号用来分隔各个空 | `(1,2),3` 是 2 个空 |
| C2 | 空的数量必须一致 | `2,3,4` 对 `2,3` 判错 |
| C3 | 必须按顺序 | `3,2` 对 `2,3` 判错 |
| C4 | 模型答案可以用中英文逗号或分号分隔 | `2；3` 对 `2,3` 判对 |
| C5 | 顿号、"或"、`(1)(2)` 编号都不算分隔符 | `2、3` 对 `2,3` 判错 |
| C6 | 两边都有标签时，标签必须一致 | `y=1,x=2` 对 `x=1,y=2` 判错 |
| C7 | 只有一边有标签时，只比较值 | `1,2` 对 `x=1,y=2` 判对 |
| C8 | 括号括起来的整体算一个空 | `(2,3)` 对 `2,3` 判错 |

### D. 选择题
| 编号 | 规则 | 例子 |
|---|---|---|
| D1 | 标准答案是按字母顺序、用半角逗号分隔的大写字母时，按选择题判 | `A`、`A,C`、`B,C,D` |
| D2 | 先由 legacy 判，判错再解析选项字母 | — |
| D3 | 多种写法都认 | `AC`、`A、C`、`(A)(C)`、`ＡＣ`、`\text{A, C}` |
| D4 | 不看顺序 | `CA` 对 `A,C` 判对 |
| D5 | 多选、漏选、带其他文字都判错 | `A`、`ACD`、`A或C` 对 `A,C` 判错 |
| D6 | 字母重复判错 | `II` 对 `I` 判错 |

### E. legacy 判题器自带的行为
| 编号 | 行为 | 例子 |
|---|---|---|
| E1 | 数值允许 0.01% 的相对误差 | — |
| E2 | 不区分大小写 | `a` 对 `A` 判对 |
| E3 | 把 `or`、`and` 当成逗号 | — |
| E4 | 删除各种单位词，包括一些单字母 | `2m` 对 `2` 判对 |
| E5 | 去掉很短的 `x=` 前缀 | `x=2` 对 `2` 判对 |

## 三、已知问题
1. **一边是方程时，标签处理会出错：**
   - 应该判对却判错：模型答 `q=\frac{p^2-1}{2}`，标准答案是 `p^2-2q=1`。
   - 可能判错却判对：标准答案是 `p=2`，模型答 `n 是奇数且 p=2`。
2. **标准答案里不能有千分位逗号：** `1,000` 会被当成两个空，模型答 `1000` 会判错。准备数据时需要检查。
